# 知识图谱、课程主题与缺口

> 本文件回答两件事：一是 DSTE 各个环节之间的衔接关系（讲课时必须讲清「为什么下一步是这一步」）；二是这份知识库能支撑哪些课程主题、还缺什么。
>
> **注意**：本文件是人工编写的内容，不由 `scripts/build_references.py` 生成；重新运行生成脚本不会覆盖它，但请勿手工清空。

## 一、四书定位（先知道自己拿的是什么）

| 简称 | 书 | 在知识库里的角色 | 讲课时怎么用 |
|---|---|---|---|
| 谢宁 | 《华为战略管理法：DSTE实战体系》 | 主干。DSTE 四大阶段、BLM 11 模块、BEM 六步、组织绩效、经营分析会、复盘与变革，全部成体系 | 课程主线照它的结构走最顺 |
| 胡红卫 | 《DSTE：从战略到执行》 | 方法论补充。作者是华为原高级副总裁、首任管理工程部总经理，第一次把 BLM、MM、BEM 放在一个框架里讲分工：「BLM 定战略、MM 定战术、BEM 定执行」 | 讲清楚 BLM 与 BEM 各自的边界时用；有汉捷咨询产品色彩，引用时注明 |
| 陈雨点 | 《华为战略解码：从战略规划到落地执行的管理系统》 | 解码环节最细。垂直一致性、水平一致性、均衡性、责任层层落实四原则；BEM 导出 CSF→CTQ→重点工作；组织保障与执行督导的具体做法 | 讲「战略怎么变成部门和个人背的数」时用 |
| 冯德刚 | 《从跟随到领先：华为管理体系重构之路》 | 全局视角。战略→流程→组织→变革，强调「只按流程操作不建团队和能力只能形似不能神似」「任何不涉及流程重构的数字化转型都是装样子」 | 收尾讲「DSTE 不只是流程」时用；有离开华为后在虎彩集团等企业的落地尝试 |

## 二、DSTE 主线与衔接关系

```
战略规划 SP（3–5 年）         谢宁 第二、三章；胡红卫 SP 三级流程
  └─ 差距（业绩差距 / 机会差距）→ 市场洞察（五看）→ 战略意图 → 创新焦点 → 业务设计
       ↓ 输出：机会点到订货、战略举措、战略控制点、战略衡量指标
战略解码 → 年度业务计划 BP 与预算   谢宁 第四章；陈雨点 第6章；胡红卫 BEM
  └─ 三次解码：公司→产品线/部门→岗位；BEM 六步；战略地图；KPI 与 PBC；全面预算
       ↓ 输出：年度经营目标、组织 KPI、重点工作、预算、PBC
战略执行与监控                 谢宁 第五、六章；陈雨点 第8章
  └─ 组织绩效管理（责任中心、考核）＋ 运营管理（经营分析会、滚动预测 3GAP+3List）
       ↓ 输出：月度/季度经营结果、纠偏动作、资源重配
战略评估与复盘                 谢宁 第七章
  └─ 战略健康度审视六维度、深度复盘
       ↓ 反哺下一轮 SP
变革治理                       谢宁 第八章；冯德刚
  └─ BTMS、先僵化后优化再固化、多产粮食与增加土地肥力
```

要点（讲课时的「承上启下」句）：

- 谢宁 p.67：「DSTE流程框架有四大阶段：战略制定、战略解码、战略执行与监控、战略评估」——整门课可以用这一句开篇。
- 谢宁 p.225：「一分规划，九分执行」——解释为什么课程重点不在战略规划本身，而在后面的解码、绩效、例会。
- 谢宁 p.227：「在战略管理体系中，存在至少三次战略解码」——解释「战略为什么解不到部门」。
- 谢宁 p.272：「企业经营管理的重点是组织绩效，而不是个人绩效」——解释经营与人力资源考核的边界。
- 谢宁 p.309：经营分析会是「管理执行与监控阶段」最重要的抓手。

## 三、书中自相冲突与需要谨慎讲的地方

- **BLM 是不是战略解码？** 胡红卫明确批评：BLM 是战略规划工具，不是解码和执行本身；谢宁与陈雨点则把 BLM 的执行设计部分作为解码的起点。讲课时按「BLM 解决战略质量，BEM 解决年度解码」来区分，不要笼统说「用 BLM 做解码」。
- **年度目标能不能调？** 谢宁在经营分析会一节强调年度经营目标不可随意调整（p.310），在复盘一节又说战略目标与环境变化时要调整（p.322 附近）。两类目标要分开讲：年度经营目标刚性，3–5 年战略目标滚动。
- **数据口径不一致**：BEM 引入年份（2011 / 2012）、无线业务亏损年限、研发投入口径、2020 年营收单位（亿元 / 亿美元）、专利口径。课程里如需引用数字，用书中页码标注并注明「书中说法」，不当作已核实的事实。
- **各书自带的隐含假设**（讲给非华为企业时务必提示）：
  - 默认企业有类似华为的管理投入能力（管理变革投入占营收 2%–3%、研发 10%–15%）。
  - 默认组织边界清晰、责任中心可定义、数据可计量。
  - 默认一把手有战略领导力且亲自推动。
  - 默认「以客户为中心」可直接转成流程和考核。
  - 胡红卫书有汉捷咨询的方法论与产品立场，案例成绩不能全部归因于方法论。

## 四、可用于课程的主题清单（按现有素材覆盖率）

| 主题 | 素材 | 覆盖度 | 建议 |
|---|---|---|---|
| 什么是经营、经营与管理的区别 | 四书均有，谢宁第一章 | 中 | 需结合用户自己的白板口径，书只能借结构 |
| 为什么需要 DSTE | 谢宁第二、三章；胡红卫序 | 高 | 可直接成页 |
| 战略规划：差距与市场洞察 | 谢宁第三章 | 高 | 五看、PEST、五力、SPAN、$APPEALS 都有原文与案例 |
| 业务设计 | 谢宁第三章（VDBD、战略控制点）、陈雨点第5章 | 高 | 如家、星巴克/瑞幸、中兴/华为制裁对比可直接用 |
| 战略解码到 BP 与预算 | 谢宁第四章、陈雨点第6章、胡红卫 BEM | 高 | 三次解码是很好的主线 |
| 责任中心与组织绩效 | 谢宁第五章 | 高但偏华为内部 | 课程里要明确「华为专属」，再给移植建议 |
| 经营分析会 | 谢宁第六章、陈雨点第8章 | 高 | 一报一会、3GAP+3List、五步分析法 |
| 复盘 | 谢宁第七章 | 中 | 战略健康度审视六维度 |
| 变革 | 谢宁第八章、冯德刚 | 中 | 适合作为收尾或「体系不是一蹴而就」的提醒 |
| 第二增长曲线 / 产业协同 | 谢宁 H0–H3 业务组合、相邻业务转型；其余三书较少 | 低 | 用户晚上讨论里提出的需求，书只能给方法论，需要外部案例补充 |

## 五、缺口

- 道通自身的组织、矩阵、责任中心、考核口径——**不在书里**，必须由公司材料提供。
- 非华为企业的落地案例（除如家、小米、诺基亚等外部案例外）——可在课程里引用前期案例研究（安克创新、多邻国、Shopify）。
- 「为什么经营」作为独立章节的素材，书里分散，需要另起结构。
- 华为官方最新口径——书籍有时效，涉及公司官方表述时需另行核对。
