# 方法（L3）

## SP制定（公司层面）三大阶段
### 出处：【谢宁 p.80「公司层面的SP制定分三大阶段：公司愿景与战略方向、产品线/销售线/职能SP和CSP」】
1. 阶段一：制定公司愿景与战略方向（战略部制定价值转移与竞争地位初步意见向EMT呈现，M1会议论证战略方向）
2. 阶段二：制定产品线/销售线/职能SP（各线制定中长期发展计划，C-PMT及EMT/IRB会议M2、M3讨论）
3. 阶段三：制定CSP公司战略规划（各线制定执行摘要，战略部整合到CSP，C-PMT论证、EMT M4审议通过，作为制定BP的指南）
- 输入：市场洞察提供的预测数据、EMT战略方向决策
- 输出：中长期发展计划全部内容（含战略衡量指标与各组织KPI指标方案）
- 适用场景：每年4月（春季）启动，持续到9月底基本完成，滚动规划
- 验证标准：各层级战略上下对齐、左右对齐，战略规划后紧接着输出战略衡量指标与KPI，避免战略管理与绩效管理两张皮


## BP制定流程（落实SP输入）
### 出处：【谢宁 p.83「如何在BP的制定中落实SP的各项输入与要求？BP的制定流程如下」】
1. 9月：BP与述职启动筹备（产业目录、销售目录、投资组合与研发费用口径、经营规则）
2. 9月底10月初：启动全面预算评审，SP向BP输入
3. 10—11月：机会点到订货分析、制定预算约束与人力预算管控条件
4. 11—12月：机会点与订货目标第一稿评审
5. 12月：制定BP（投资组合规划及业务规划，导出重点工作与全面预算、人力预算）
6. 次年1月：投资组合与研发费用、重点工作、全面预算、人力预算评审，输出BP与述职报告，制定组织KPI目标值与高管PBC
7. 次年3月：KPI目标值评审、BP与述职、PBC沟通签署
- 输入：SP六个方面输入（市场空间/机会点到订货、战略优先级、战略举措、战略目标、人力规划、预算）
- 输出：体系目标策略行动计划、机会点到订货、关键财务指标/预算/组织KPI
- 适用场景：前年10月（秋季）启动，持续到次年3月底基本完成
- 验证标准：资源利用效率提高、产品目标明确、年度预算清晰，BP承前启后、上下对标


## 5Why分析法（根因分析）
### 出处：【谢宁 p.104「5Why分析法，又称5问法，也就是对一个问题点不断询问若干次为什么」】
1. 对一个问题点不断询问若干次为什么
2. 找到问题发生的完整链条
3. 沿因果关系链条顺藤摸瓜，直至找出根本原因
- 输入：一个待分析的问题点（差距/故障）
- 输出：问题的根本原因及解决方法
- 适用场景：深挖业绩差距与机会差距的根本原因；不限定只做5次，有时3次有时10次，直到找到根本原因为止
- 验证标准：避开主观或自负的假设与逻辑陷阱，找到可阻止问题再次发生、有助于实现目标、便于实施的「关键的少数」根本原因

### 出处：【胡红卫「第三章第二节」原文'所谓5why分析法，又称5问法，即针对一个问题点连续提出5个为什么来追问'】
1. 针对问题点连续追问'为什么'，层层深入，直到找到根本原因（不一定严格5次，3次或10次以上均可）
2. 业绩差距：先分析什么直接制造差距，再层层分析为何没发现、为何没纠偏
3. 机会差距：分析错过的原因或未来兑现机会所需的能力差距
- 输入：业绩差距与机会差距现象描述。
- 输出：根本原因（多归为组织能力不足）、纠正措施。
- 适用场景：双差分析根因分析，经营分析会根因分析，任何需要探究问题根源的场景。
- 验证标准：摒弃主观假设和逻辑陷阱，从结果出发沿因果关系链条直至揭示根本原因。


## 关键成功因素分析法（鱼骨图法）
### 出处：【谢宁 p.104「关键成功因素分析法（鱼骨图法）是一个非定量的工具」】
1. 列出导致问题的所有潜在原因
2. 分析各原因之间的相互关系
3. 从中找到根本原因
- 输入：反映问题为什么会发生的现状信息
- 输出：根本原因
- 适用场景：非定量地找出业绩/机会差距的根本原因，与5Why结合使用
- 验证标准：团队聚焦于问题原因而非症状、历史或个人观点


## SPAN战略定位分析（筛选战略机会点）
### 出处：【谢宁 p.138「对各个战略机会点（即细分市场）进行深入分析，筛选出哪些细分市场作为企业的目标细分市场」】
1. 确定市场吸引力四要素（市场规模、市场增长率、盈利潜力、战略价值）权重系数（合计100%）
2. 针对细分市场对各要素评级（高/中/低对应5/3/1分）或直接打分，计算市场吸引力总得分
3. 识别业界最佳竞争对手，从$APPEALS八要素或22要素中选择关键要素评估竞争地位
4. 在SPAN矩阵画出泡泡图定位每个细分市场
5. 按四象限采取对应策略与行动
- 输入：市场洞察的细分市场机会点
- 输出：目标细分市场选择、相应产品及服务策略、投资组合管理依据
- 适用场景：看机会阶段筛选战略机会点（市场机会），为最终战略规划提供决策依据
- 验证标准：每个细分市场完成战略定位分析与财务分析（FAN），确定吸引力并量化财务收益


## 市场细分的基本原理（Who/What/Why三维）
### 出处：【谢宁 p.116「市场分析的基本原理是，至少从谁购买（Who）、购买什么（What）、为什么购买（Why）三个维度进行分析」】
1. 从谁购买（Who）维度分析
2. 购买什么（What）维度分析
3. 为什么购买（Why）维度分析
- 输入：市场/客户调研数据
- 输出：满足独特性、重要性、可衡量性、持久性、可识别性要求的细分市场
- 适用场景：看市场/客户阶段，输出战略机会点前提与有效业务战略基础
- 验证标准：找到能充分区分需求差异且与自身能力相匹配的细分维度，满足五性要求


## BEM六步法
### 出处：【谢宁 p.236「BEM方法论主要有两个阶段」】
1. 第1步明确战略方向及其运营定义
2. 第2步导出中长期关键战略举措（CSF）
3. 第3步导出战略衡量指标（战略KPI）
4. 第4步确定年度业务关键措施＆目标（CTQ-Y导出）
5. 第5步分解年度业务关键措施＆目标（TPM/CPM/BPM）
6. 第6步确定年度重点工作
- 输入：SP阶段输出的战略规划成果、CSF、战略意图与业务设计
- 输出：组织KPI池、年度重点工作、可执行计划、绩效计划
- 适用场景：战略规划落地到年度业务计划和组织/个人绩效时
- 验证标准：工作计划/绩效计划可执行，是衡量战略解码及战略管理水平的核心标准


## IPOOC法导出CSF构成要素
### 出处：【谢宁 p.247「华为内部使用的是IPOOC方法」】（华为专属）
1. 从Input（资源/信息）展开
2. 从Process（影响战略举措达成的关键活动过程）展开
3. 从Output（流程直接输出）展开
4. 从Outcome（内外部客户视角收益）展开
5. 针对构成要素设计备选KPI
- 输入：CSF（战略举措，如「提升价值市场份额」）
- 输出：CSF构成要素及备选战略KPI
- 适用场景：CSF不明确、无法直接导出KPI时
- 验证标准：构成要素采用动宾短语，一个CSF最多不超过5个构成要素


## 战略KPI筛选四标准
### 出处：【谢宁 p.248「战略衡量指标筛选评价标准有四个方面」】
1. 战略相关性
2. 可测量性
3. 可控性
4. 可激发性
- 输入：战略备选指标
- 输出：合适的战略衡量指标
- 适用场景：从CSF构成要素中筛选战略KPI时
- 验证标准：按平衡计分卡维度检验指标平衡性，确保支撑战略达成


## 部门战略解码五步骤法
### 出处：【谢宁 p.258「部门战略解码有五个步骤」】
1. 确定部门使命愿景定位
2. 对公司/上级战略学习理解输出战略学习汇报
3. 输出述职报告与PBC
4. 制定部门年度重点工作WBS计划
5. 输出部门指标定义及报表
- 输入：公司/上级部门完成年度业务计划内容（战略目标、关键任务里程碑计划、财务人力预算）
- 输出：部门战略解码成果（部门KPI、重点工作、WBS、指标字典）
- 适用场景：下级部门承接上级年度业务计划时
- 验证标准：重点工作符合SMART原则，WBS近期详细远期只明确里程碑


## 组织绩效KPI设计（流程—职责方法）
### 出处：【谢宁 p.285「流程—职责方法，部门是通过流程来创造价值」】
1. 基于端到端流程价值和组织职责设计
2. 分析价值链和业务流程识别价值创造驱动因素
3. 识别流程KPI
4. 归纳提炼组织KPI
- 输入：组织职责定位、端到端流程
- 输出：组织KPI集合
- 适用场景：设计组织绩效KPI、需横向协同（职能KPI与流程KPI关联时）
- 验证标准：职能KPI是流程KPI过程性指标时，应以流程KPI为主


## 四比法定目标值
### 出处：【谢宁 p.292「华为在确定组织绩效KPI的目标值时，采用四种比较法」】（华为专属）
1. 与行业发展趋势比
2. 与竞争对手发展比
3. 与企业内同类业务比
4. 与自己过去比
- 输入：市场情况、竞争对手、自身能力数据
- 输出：组织绩效KPI目标值（底线值/达标值/挑战值）
- 适用场景：确定组织绩效KPI目标值时
- 验证标准：市场占有率等相对指标比绝对指标更能发现问题


## 经营分析报告撰写（业务报告五要素）
### 出处：【谢宁 p.313「一份高质量的业务报告通常包含五个方面的内容」】
1. 全年预测
2. 聚焦差距和根因分析
3. 输出机会清单
4. 配套相应资源和形成明确行动计划
5. 输出待决策事项
- 输入：经营主报告（CFO）与业务报告（业务主管）
- 输出：高质量经营分析报告，支撑经营分析会决议
- 适用场景：召开经营分析会前
- 验证标准：五要素对齐（五个一致性：机会、目标、策略、行动计划、资源配置）


## 滚动预测动态监控（3GAP+3List）
### 出处：【谢宁 p.314「滚动预测的主要工具是3个GAP（差距）和3个List」】
1. 预测内抓执行预测外找机会（GAP1）
2. 加强预测与实际差距分析（GAP2）
3. 对比本期与上期预测（GAP3）
4. 确定类清单抓执行重效率
5. 风险类清单清风险
6. 机会类清单找机会赢机会
- 输入：经营计划/目标、KPI、月度数据
- 输出：任务令、偏差分析、动态资源配置
- 适用场景：月度经营分析会、年度经营目标达成监控
- 验证标准：通过机会赢取把预测外转预测内，建立经营管理闭环


## 五步分析法（差距根因）
### 出处：【谢宁 p.315「主要的方法是五步分析法」】
1. 打开分类（按产品/渠道/区域/客户群）
2. 数据量化
3. 归因于内
4. 解剖麻雀
5. 构建流程机制
- 输入：实际业绩与目标/预算之间的差距
- 输出：根本原因及应对措施
- 适用场景：经营分析聚焦差距及根因时
- 验证标准：找到根本原因而非表面现象，避免每月打地鼠


## 战略健康度审视六维度法
### 出处：【谢宁 p.322「按照下面六个维度展开战略健康度审视」】
1. 机会（抓住/未抓住什么机会）
2. 客户（为何选择/不选择我们）
3. 竞争（输出HTL向对手学习、HTB打击对手）
4. 产品竞争力
5. 运营效率
6. 组织关系和管理
- 输入：上一轮战略规划和战略解码期间的市场结果与业务进展
- 输出：下一轮战略规划/战略指引输入
- 适用场景：新一轮战略规划前，一年一次
- 验证标准：回顾过去检讨差距，为企业自愈提供输入


## TPM成熟度评估
### 出处：【谢宁 p.326「TPM将管理体系的成熟度评估划分为五个层级」】
1. 划分五层级（试点级/推行级/功能级/集成级/世界级）
2. 按领域评分（九个领域×七个评估项目）
3. 参与人员沟通共同打分（增量打分）
4. 对得分升降原因说明，形成会议纪要
5. 输出优先级高的问题清单及行动计划
- 输入：管理体系推行现状
- 输出：变革进展评分、问题清单、改进计划
- 适用场景：衡量管理体系推行程度与效果、找出推行不足时
- 验证标准：跨国公司TPM应达3.5分，3.5分以下IPD封闭在研发内部未与相关流程关联


## 变革管理破解抵制
### 出处：【谢宁 p.335「应该怎样破解这些难题」】
1. 深入洞察市场变化、学习标杆企业实践，让干部员工目睹关键事件激活思想
2. 选取敢于破局的优秀干部员工进入示范项目由点带面
3. 深层次文化支持，认同变革是常态
- 输入：组织和个体的思维惯性与行为惰性
- 输出：变革的可执行落地
- 适用场景：变革受到「牛人」及其利益相关者抵制时
- 验证标准：变革阻力化解，领导变革决心是重中之重


## 市场洞察五看法
### 出处：【谢宁 p.108「华为在市场洞察上有一套方法论，称为'五看'」】
1. 看趋势（PEST宏观+行业环境分析）
2. 看市场/客户（市场地图+客户细分+$APPEALS需求分析）
3. 看竞争（波特五力+$APPEALS雷达图）
4. 看自己（BMC商业模式画布+四看后SWOT）
5. 看机会（SPAN战略定位分析+FAN财务分析）
- 输入：市场/客户信息、竞争情报、行业数据、经营数据、商业智能信息
- 输出：战略机会点、机会窗战略机会点
- 适用场景：战略规划前例行化市场洞察
- 验证标准：不遗漏战略机会，不忽视重大风险，输出战略机会点。


## 差距根因分析（5Why+鱼骨图）
### 出处：【谢宁 p.103「推荐采用关键成功因素分析法（鱼骨图法）和5Why分析法」】

- 输入：业绩差距、机会差距

- 适用场景：BLM差距分析环节、根因分析
- 验证标准：找到'关键的少数'根本原因，能阻止问题再次发生。


## IPOOC导出CSF构成要素
### 出处：【谢宁 p.247「华为内部使用的是IPOOC方法，从Input……四个维度对CSF展开」】（华为专属）

## 年度业务关键措施目标分解（TPM/CPM/BPM）

2. 生命周期法：按事物全周期管理阶段划分（如IPD六阶段）
3. 对象转换法：按对象类型分段（如LTC按线索/商机/合同）
4. 树状分类法：用于使能类和支撑类流程层层解构
- 输入：业务流程、管理逻辑
- 输出：流程架构
- 适用场景：构建流程架构、规划运作/使能/支撑流程时。
- 验证标准：符合业务逻辑关系，主线清晰易执行，分层分级。
