# hw-dste：DSTE 专家

一个面向 Claude Code / Agent Skills 的技能：让 AI 以「DSTE 专家」的方式回答经营与战略管理的问题——给判断、给出处、讲边界，缺关键信息时先反问，而不是背框架名词。

## 它解决什么

很多企业想把「从战略到执行」这套机制建起来，但看材料时容易遇到两个问题：一是资料多、说法杂，不知道哪个环节该信谁；二是网上的框架很多，却没人说清「这套做法在什么条件下成立、搬到自己公司要改哪里」。

这个技能把华为 DSTE 相关的四本书提炼成一个按主题组织、每条带出处的素材库，并配一套专家的回答规则，你可以随时向它提问：

- 经营分析会是什么、怎么开、一年开几次合适？
- 战略解码到底解几次，各解成什么？
- BLM 和 BEM 是什么关系，先做哪个？
- 责任中心怎么分，华为的做法能不能搬到我们公司？
- 年度经营目标能不能年中调整？

## 专家怎么回答

每次回答分四步：

1. **判断问题类型**：概念、做法步骤、判断建议、迁移判断、对比取舍、事实核实，不同类型答法不同。
2. **查依据**：优先从 `references/` 取带出处的条目。
3. **给判断**：先给结论，再给依据，最后讲边界（华为专属还是通用方法、作者之间有没有分歧、这个方法的前提你有没有）。
4. **先问再答**：判断类问题缺少公司规模、战略规划是否存在、谁背指标、一把手参与程度等关键信息时，先问最多三个问题。

完整规则见 [SKILL.md](SKILL.md)。

## 素材结构

```
references/
├── knowledge_graph.md      四本书定位、DSTE 主线衔接、作者冲突、课程主题与缺口
├── concepts.md             概念定义与相近概念区分（92 条）
├── frameworks.md           框架组成与四书差异（94 条）
├── methods.md              方法步骤、输入输出、判断标准（61 条）
├── principles.md           原则、边界、作者间的冲突与调和（78 条）
├── cases.md                可讲的真实案例（72 个）
├── glossary.md             术语与英文缩写（103 条）
├── huawei_vs_portable.md   华为专属做法 vs 一般方法
└── verification_notes.md   待核条目、书中数据口径不一致、各书立场提示
```

每条都标了出处，格式如：【谢宁 p.88「BLM是一套战略管理和领导力发展工具……」】。标「华为专属」的是华为内部制度或约定，不能直接当作其他公司的做法。

## 素材来自哪里

| 简称 | 书 | 作者 |
|---|---|---|
| 谢宁 | 《华为战略管理法：DSTE实战体系》 | 谢宁 |
| 胡红卫 | 《DSTE：从战略到执行》 | 胡红卫 |
| 陈雨点 | 《华为战略解码：从战略规划到落地执行的管理系统》 | 陈雨点 |
| 冯德刚 | 《从跟随到领先：华为管理体系重构之路》 | 冯德刚，清华大学出版社 2024 |

素材是用 [weitzu-com/book-to-skill](https://github.com/weitzu-com/book-to-skill)（书道）的思路、按「概念 / 框架 / 方法 / 原则」四层提取的，四本书合并后按主题组织，而不是一本书一个技能。构建脚本在 `scripts/`：

- `extract_pdf.py`：PDF 文字层提取（PyMuPDF），按页保留页码标记；
- `extract_epub.py`：EPUB 正文提取，按 OPF 顺序保留章节；
- `verify_sources.py`：逐条把引用片段拿回原书核对；
- `build_references.py`：合并解析结果生成七份素材文件。

## 使用

把整个仓库放进 Claude Code 的技能目录，例如：

```bash
git clone https://github.com/franklin625-xn/hw-dste.git ~/.claude/skills/hw-dste
```

然后在对话里直接提问，或者用 `/hw-dste` 触发。

## 质量与边界

- **溯源校验**：脚本逐条核对，谢宁 173/209、胡红卫 96/98、陈雨点 67/68、冯德刚 67/68 条能在原书全文找到引用片段；没对上的在 `references/verification_notes.md` 里列出，引用前需人工回原文核对。
- **书中数据不一致**：BEM 引入年份、研发投入口径、2020 年营收单位、专利口径等，笔记里都标出来了，回答时说明是「书中说法」。
- **不含公司内部信息**：本仓库只有公开出版书籍的提炼，不包含任何企业的内部制度、数据或组织架构。
